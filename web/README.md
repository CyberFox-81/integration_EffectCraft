## Embedding bridge

Started with `?host=parent` inside an iframe, EffectCraft talks to its parent window with `postMessage`. It only accepts messages from the parent window on its own origin, and only sends to that origin. Every message is a plain object with a `type`:

| Message | Direction | Fields | Meaning |
|---|---|---|---|
| `effectcraft:ready` | EffectCraft → parent | `version` | The app is listening; send a file now. |
| `effectcraft:open` | parent → EffectCraft | `name`, `bytes` (`ArrayBuffer` or `Uint8Array`) | Open this file, as File › Open would. |
| `effectcraft:save` | EffectCraft → parent | `name`, `bytes` (transferred `ArrayBuffer`) | A file EffectCraft would otherwise download: Save, Save As or Export. `name` is a file name, or a path the parent picked. The parent stores the file and reports success or failure itself. |
| `effectcraft:dirty` | EffectCraft → parent | `dirty` (boolean) | Unsaved changes appeared or went away. |
| `effectcraft:failed` | EffectCraft → parent | `error` | The app couldn't start (for example, no WebGPU or WebGL2). |

Files the parent sends keep its path under `/host` in EffectCraft's file table, so a saved project refers to its footage by their paths on the parent's side. Before a project opens, EffectCraft asks for the footage it refers to that isn't there yet:

| Message | Direction | Fields | Meaning |
|---|---|---|---|
| `effectcraft:need` | EffectCraft → parent | `paths` | Footage an opened project refers to. |
| `effectcraft:file` | parent → EffectCraft | `path`, `blob` or `error` | One of them, or why it can't be had. |

`effectcraft:open` also carries `path` (the file's path on the parent's side) and sends a `Blob` rather than bytes. A saved project's `name` is the parent's path when it lives there; a new project or a render goes by its file name, and the parent asks where it goes. In host mode the last session, the demo and the recovery offer don't open, the session isn't kept in browser storage, and the parent guards leaving the page.

Without `?host=parent`, EffectCraft behaves exactly as upstream: saved files download.
